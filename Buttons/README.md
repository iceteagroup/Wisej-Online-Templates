  <h2>2. WHAT TO LOOK FOR</h2>
  <ul>
    <li>Using Padding to increase the internal margins.</li>
    <li>The size of the image is set in the theme, except for Overlay and BackgroundImage.</li>
    <li>You can change the size of the image when using an ImageList.</li>
    <li>Wisej can use embedded image resources, theme images, external URLs, and local image files.</li>
  </ul>

  <h2>3. HOW TO CREATE YOUR OWN</h2>
  <p>
    Drop a button on a page and change all the image-related properties to play with the endless possibilities.
